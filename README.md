# Delcom Link Tree (ifs24016-pabwe2026-sk-p6-svelte)

Svelte 5 + Vite + JavaScript, custom router (History API), Tailwind CSS v4, Bun. Port 3004.

```powershell
bun install
bun run dev            # http://localhost:3004
bun run test
bun run test:coverage  # threshold 100%
bun run build
bun run preview
```

Catatan: tes komponen ditulis tanpa sempat dijalankan; jika ada yang gagal,
perbaiki berdasarkan pesan error, jangan menurunkan threshold coverage.
